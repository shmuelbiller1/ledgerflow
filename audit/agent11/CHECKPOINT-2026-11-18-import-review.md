A duplicate with a different name but shared identifier can be missed and the server creates a new contact, complicating party records and reconciliation. Reproduce with an empty cached list and `truncatedCollections.customers=true`, or a failed customer subscription after load, then upload a valid new-name contact. **Fix:** show an incomplete warning and suppress the definitive no-match message; the server remains authoritative for exact-name skips. Component tests cover capped and failed list. Remaining: no guarantee of detecting all identifiers or concurrent changes; J-3 server workflow remains open.
