## Changes

- Five fixed phone actions: Home, To review, New (centre +), Reports, More.
  Home/review/reports use the existing screen IDs; More opens the existing navigation.
  The bar and content reserve both 64 px and the device safe-area inset.
- Phone and desktop New use the same keyboard-accessible, named creation dialog.
  Invoice, customer, bill, vendor and journal entry open their actual existing editors.
- Typed creation links live in `recordLinks.ts`: `#sales/invoice/new`,
  `#sales/customer/new`, `#purchases/bill/new`, `#purchases/vendor/new`,
  `#ledger/journalEntry/new`. They are distinct from saved-record links and are
  consumed once, without waiting for a record list to load. Unknown/wrong-screen
  targets do not request a form. Ordinary navigation cancels a pending request.
- Journal creation selects the accountant view even when the owner view is active.
- Ctrl/Command+Alt+I, +B and +J open invoice, bill and journal entry respectively.
  They are listed in the shared Keyboard shortcuts dialog. Typing and open dialogs
  retain their keys; viewers cannot open a creation form through these new paths.

No amounts, financial services, posting code, database schema or server code changed.
Existing editors and their save paths remain responsible for all writes.
