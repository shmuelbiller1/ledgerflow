### A-265 — reduced motion

- Previous `MotionConfig reducedMotion="user"` skipped transforms but still animated opacity. New `ReducedMotionProvider` combines the OS media feature and the existing in-app preference, and uses Motion's supported `skipAnimations` configuration to finish fades/springs as well.
- The in-app `html.reduce-motion` class previously had no CSS rule. It now finishes transitions/animations and disables smooth scrolling. Both CSS paths reset delays as well as durations: a 30-second delay must not survive a near-zero duration.
- Component regression checks live in-app preference changes without remounting.
- Two full-app Chromium journeys emulate OS reduce / OS no-preference + app reduce. Sample the invoice modal's actual animated panel (not its static dialog wrapper) in its first painted frames; check final opacity/transform, delayed CSS duration/delay, Escape and returned focus.
