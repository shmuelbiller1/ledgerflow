- Every main registry screen (including discovered plugins) receives an advanced flag and business recommendation list; `*` means cross-business. Existing business/template IDs are used. Unrecognized legacy types keep all Pro recommendations rather than losing tools.
- Pro mode reveals advanced recommendations relevant to the business; it also filters the module-page strip. A screen opened from discovery keeps its selected context even with Pro off.

It does not override disabled modules, developer-only screens or existing owner/admin gates. It points to Settings → Modules for disabled modules. No module settings, permission policy, server, schema or posting rules changed.
- Bookmarks remain discoverable with Pro off, using the same module/developer/owner eligibility checks. Search index and existing route handlers remain intact.
