## What was built

### R-7 — "Why did this number change?" (new)

The queue asks: *on P&L and balance sheet, a report total compared with last month shows the entries that make
up the difference (largest first, with links); tests with hand-worked figures.*

| Piece | File | What it does |
|---|---|---|
| the change, ranked | `src/lib/statementChange.ts` | `buildStatementChange(current, prior, { signs })` takes the statement's **own** account figures and returns every account that moved, ranked by how much it moved the figure. Income counts `+1` toward net profit, cost of goods and expenses `−1`. An account that did not move is counted, not listed; a section with no sign is counted but does not move the figure. The parts are guaranteed to add to the whole (a test checks it), so the panel cannot disagree with the statement. |
| the entries | `src/lib/reportExplain.ts`, `src/hooks/useFigureExplanation.ts` | The request body, the answer's shape and the "is this really an explanation?" check moved out of the drill-down dialog into one module, used by both the dialog and the new panel. The hook asks the existing `POST /api/v1/reports/explain` (the full history, not the browser's capped copy) and never shows a previous request's lines. |
| the panel | `src/components/reporting/StatementChangePanel.tsx` | The accounts with *now / before / change / effect on this figure*, each openable to the posted lines behind it — for a flow, **both** periods (this period's entries minus the period before's *is* the change), for a balance, the single range of days between the two dates. Every line links to its invoice/bill/entry. Failure says so and offers "Try again"; never an empty list dressed up as "nothing here". |
| the profit & loss | `src/components/ledger/ProfitAndLossView.tsx` | A **"Why did net profit change?"** button beside the comparison control, shown only when a previous-period comparison is on (a budget has no entries to explain, and cash basis returns one server total). |
| the balance sheet | `src/components/ledger/BalanceSheetReport.tsx` | **"What moved in total assets"** and **"What moved in total liabilities"** beside the comparison, using `movementWindow` (the day after the compared date through the as-of date — the days whose entries *are* the movement). Equity is deliberately left out: the subtotal printed beside it also carries retained earnings, which is not an account, so an account-by-account list could not add up to it. |
