- Explicit local database read/query/subscription/batch transport. Batch changes publish only after storage succeeds; references and posting capture reject discarded sample sessions, including leave/re-enter with the same workspace ID.
- Local entity CRUD and unchanged document builders through their existing capture-only context; document plus captured entries publish atomically. Real workspace posting paths and all builders are unchanged. This adaptation still needs lead review.
- Local document numbers shared by invoice/bill/estimate saves and Document numbering Settings, with used-number refusal. Sample numbers default to SAMPLE-*.
- Projects, budgets, inventory, estimates, dimension labels and related/inline metadata editing use the local sample scope. Price lists and price-list CSV import/Undo save locally with the existing validator. Alerts and invoice/bill stages save locally; no nightly alerts are sent.
- Country sample selection/reset replaces the same local tables that forms use, rather than only replacing the visible cache.
- One persistent banner: **Sample company — sign up to keep your own**. Attachment uploads are explicitly unavailable, not silently sent or reported as saved.
- Bootstrap fetch/XHR guard rejects network actions while the sample session is active. This is defense in depth, not server authorization or proof that every possible transport has been audited.
