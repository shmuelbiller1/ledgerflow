## A-273 — the invoice print test loads a real PDF

`e2e/print-styles.spec.ts`, the invoice case. The guest has no token, so the document endpoint
would refuse; the spec now stubs `**/api/v1/documents/invoice/*/pdf*` with a small one-page PDF
fixture (`pdfWithText`) carrying `Invoice DEMO-US-001` and `Total: $16,500.00` (the demo seed's
January invoice is 1,650,000 cents). After opening the preview the spec waits for the document
frame, asserts the error state is absent, fetches the frame's blob and checks the bytes contain
`DEMO-US-001` and `16,500.00`, then runs the same print-media isolation checks as before
(one print root, toolbar hidden, no buttons or navigation, root full width).

**1/1 Chromium** (4.6 s). Non-vacuous by construction: without the stub the preview shows
"Unable to render PDF" and there is no frame to read; with a fixture missing either string the
byte check fails.

## A-276 — the phone pass on the ten A-272 screens

`e2e/phone-a272-screens.spec.ts`, **10/10 Chromium** at 390×844, guest workspace, the app's own
API stubbed, opened the way a reader opens them (`/#<tab>`): Payments, Credit notes, Estimates,
Purchase orders, Recurring, Audit trail, Budgets, Fixed assets, Loans, Time. Per screen: its own
heading is visible and fits the phone, the page never scrolls sideways, every scroll box fits and
every table fits or scrolls inside a box that does, every touch target measures at least 44 px
(checkboxes/radios excluded — their label is the target), and axe reports no serious or critical
finding in `#main-content` (colour contrast is `contrast.spec.ts`'s, as in `ai3-report-audit`).

The first run found three real phone defects, all fixed in this PR:

1. **Payments** — the register's scroll box was 800 px wide (37…837): the root div is a flex
   item with `min-width: auto`, so the 800 px table blew it out to 874 px and `#main-content`
   clipped it — the right-hand columns were unreachable, not scrollable. Fixed with
   `w-full min-w-0` on the root (`PaymentsView.tsx`).
2. **Purchase orders** — axe `scrollable-region-focusable` (serious): the three table scroll
   regions were not keyboard-reachable. Fixed with the repo's `role="region" aria-label tabIndex={0}`
   pattern (`PurchaseOrdersView.tsx`).
3. **Audit trail** — the Export button was clipped off the 390 px edge (header row never wrapped).
   Fixed by stacking the header on phones (`AuditTrail.tsx`).
