## D-85 — Dashboard shows cash, owed to you, you owe and profit first

- The hero and the Owner/Accountant lens switch are gone. The page starts with a plain heading
  ("Dashboard"), one sentence, and the single primary action (Add Entry, 44 px).
- The four cards a shop owner opens the page for are now the first row, in that order:
  **Cash**, **Owed to you**, **You owe**, **Profit** (`DASHBOARD_WIDGETS` order in
  `src/lib/dashboardOverview.ts`; labels in `src/components/dashboard/DashboardWidgets.tsx`).
  The widget ids did not change, so a layout saved before this branch keeps working.
- The setup checklist that used to sit above the numbers moved below them, and its words are plain
  ("Finish setting up your books", "1. Chart of accounts", "2. Import your history",
  "3. Check the balances").
- Money is unchanged: the four cards still read `dashboardComparison(...)` →
  `computeBalanceSheet` / `computeProfitAndLoss`. No calculation, filter or period function changed.

## D-90 — Settings: five sections and one search box

- New `src/lib/settingsSections.ts` maps every settings screen to one of five sections:
  **Your business**, **Accounting**, **People & messages**, **Data & automation**, **App & plan**,
  each with one plain sentence.
- `Settings.tsx` renders those sections as a vertical list with a **Find a setting** search box.
  The selected screen has `aria-current="page"` and is scrolled into view inside the list only.
- **Every registered screen stays reachable.** `settings-navigation.test.tsx` fails if
  `SETTINGS_TABS_REGISTRY` contains an id with no section, and a screen with no section is shown
  under "Other" instead of disappearing.
- Search matches the visible English and Hebrew name, the section name and the id, word by word;
  no match says so and offers "Show all settings".
- The invented words are gone ("Precision Core", "institutional rule bridges", "enterprise-grade
  security protocols", the "Documentation Protocol" developer card). The developer card is not
  needed: each screen already carries its own help text, which the page now shows under the title.
- The same component renders for a chosen screen, so no settings behaviour changed.

## D-92 — Sidebar: the "Worlds" box is named, explained and actionable

- Renamed to what it contains: **Projects** (when the workspace has projects, with the budget you
  set) or **Balances by account type** (the total of each account type in the books), with a
  one-line explanation of the figure.
- Account types read as words ("Cost of goods", not "COST_OF_GOODS").
- The rows are no longer fake buttons. One real action sits under them: **Open projects** or
  **Open balance sheet** (which also selects the balance sheet report), 44 px tall.

## Small shared fix

`EmptyState`'s action used the all-caps `uppercase` style the UI guide forbids on buttons; it is
now sentence case with a 44 px target and the same behaviour.
