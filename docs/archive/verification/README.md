# Archived verification notes (moved 10 Nov 2026 by AI #13; nothing deleted)

Evidence notes for **finished** tasks, moved here word for word from `docs/verification/`.
Old path → new path: `docs/verification/<name>.md` → `docs/archive/verification/<name>.md`, so any
historical message, tracker item or report that names the old path still finds the file by name.

A note stayed in `docs/verification/` when anything live points at it: `CURRENT_WORK.md`,
`docs/RELEASE_GATE.md`, an open queue item or a message from the last two weeks in
`docs/COORDINATION.md`, `docs/FOR_YOU.md`, `docs/TRACKER.md`, a unit test, an e2e spec, a kept
audit report, or another kept note. Screenshots stay where they are: `docs/verification/images/`
is written by e2e specs (`e2e/plain-language.spec.ts`) and `docs/verification/assets/` belongs to
kept notes.
